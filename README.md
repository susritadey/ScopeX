# BirdScope - Team ScopeX
GEC Bharatpur | Startup Quest

### Idea
Keoladeo National Park me tourists ko bird ka naam nahi pata chalta. Humara AI app photo se turant bird pehchan lega.

### Features

- Tell name in Hindi + English
- Offline for jungle
- eBird data
